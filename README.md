# Навигатор ЖКХ (г. Курган) — MAX Bot

Интеллектуальный чат-бот для платформы MAX, предназначенный для быстрого получения справочной информации о многоквартирных домах города Кургана.

## Назначение решения

Решение предназначено для жителей города Кургана, которым необходимо быстро узнать актуальную информацию о своём многоквартирном доме:
* Название и сайт управляющей компании (УК);
* Актуальные базовые тарифы ЖКХ;
* Планируемые работы по капитальному ремонту;
* Прямые ссылки на официальные государственные ресурсы (ГИС ЖКХ, Фонд капремонта).

Бот решает проблему фрагментированности информации, предоставляя «единое окно» для удобного и быстрого получения справок.


## Основной пользовательский сценарий

1. **Инициализация:** Пользователь открывает диалог с ботом и отправляет команду `/start` (или нажимает системную кнопку «Запустить»).
2. **Приветствие:** Бот приветствует пользователя по имени и предлагает ввести адрес дома.
3. **Ввод адреса:** Пользователь вводит адрес (например, `Кирова 117` или с возможной опечаткой, например `Корева 117`).
4. **Обработка:** Бот обрабатывает запрос, задействуя модуль нечёткого поиска (Fuzzy Search) для распознавания опечаток и вариативности написания улиц.
5. **Выдача результатов:** Бот отправляет структурированную карточку дома со сведениями об УК, тарифах и капремонте.
6. **Навигация:** Пользователь может нажать кнопки меню для знакомства с функционалом («Помощь») или для проверки другого адреса («Новый поиск»).


## Состав и архитектура решения

Решение построено по монолитной контейнеризированной архитектуре и включает следующие компоненты:

* **Runtime / Backend:** Node.js (v20) — файл `bot.js`, управляющий логикой диалога, сетевыми запросами к API MAX и обработкой входящих событий.
* **База данных:** SQLite (`houses.db`) — локальная реляционная БД с оптимизированным индексом, доступная в режиме чтения (`readonly`) для высокой скорости поиска и защиты данных.
* **Поисковый движок:** Библиотека `fuse.js` — модуль нечёткого текстового поиска по адресному классификатору и улицам.
* **Контейнеризация:** Docker & Docker Compose — изолированное окружение для моментального и воспроизводимого развертывания на любой инфраструктуре.


## Зависимости проекта (`package.json`)

* `node-fetch` (`@2`) — модуль для выполнения HTTP-запросов к API платформы MAX.
* `better-sqlite3` — высокопроизводительный драйвер для работы с базой данных SQLite.
* `fuse.js` — библиотека для алгоритмов нечёткого поиска адресов.

## Docker-конфигурация и порядок запуска

Решение полностью готово для воспроизводимого запуска в контейнере Docker.

### Состав файлов контейнеризации в репозитории:
* `Dockerfile` — файл сборки образа (на базе `node:20-slim` с установкой утилит сборки native-модулей).
* `docker-compose.yml` — конфигурация сервиса и запуск контейнера.
* `.dockerignore` — исключения (отсекает `node_modules`, `.git` и локальные логи для урезания времени сборки до < 1 минуты).
* `.env.example` — безопасный шаблон переменных окружения без реальных ключей.
